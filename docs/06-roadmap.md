## Decisions already made

- **Single Vite app, no backend.** See [Architecture](02-architecture.md#why-no-nextjs-or-nestjs).
- **InDesign export is IDML.** A browser cannot write `.indd`; InDesign opens IDML natively.
- **PDF is generated by a library**, never by the browser's print dialog, so text stays selectable and layout is identical everywhere.
- **Grammar checking stays local.** The browser's spellchecker by default; an optional self-hosted LanguageTool container may be added to Compose.
- **Arial and Times New Roman are not shipped.** The user's installed copies are used.

## Open questions

- Which interface languages ship first after English?
- Should Google Fonts be proxied through a self-hosted mirror option for users who want zero third-party requests?
